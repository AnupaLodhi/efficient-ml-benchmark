Combined compression: pruning can be applied first, followed by quantization. Our benchmark then measures whether both techniques can be combined without an unacceptable loss in predictive performance.
Research note: zeroing weights through unstructured pruning does not automatically shrink a densely stored model file or guarantee faster CPU execution. Hardware and runtime support matter.
