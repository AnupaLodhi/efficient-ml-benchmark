ABOUT THE RESEARCH

EfficientML Benchmark

A reproducible machine-learning benchmarking framework for studying accuracy–efficiency trade-offs across neural-network compression methods using ResNet-18 and CIFAR-10.

CORE RESEARCH QUESTION

How small and efficient can a neural network become while retaining useful predictive performance?

Experimental workflow

The framework follows the same broad pipeline for each compression experiment so model quality and efficiency can be studied together.

01

Train

Train a ResNet-18 baseline on CIFAR-10 and save its evaluation metrics.

02

Prune

Zero low-importance weights at multiple sparsity levels and fine-tune the network.

03

Quantize

Evaluate FP16, dynamic INT8 and static INT8 representations.

04

Combine

Apply pruning followed by quantization to study interacting compression effects.

05

Benchmark

Measure predictive performance, storage, latency, throughput and other efficiency metrics.

06

Analyze

Compare trade-offs and document hardware-specific behavior and experimental limitations.

Current research limitations

Short baseline training

The current local baseline was trained for three epochs to validate the end-to-end experimental pipeline rather than establish a converged final benchmark.

Different fine-tuning budgets

Some pruning runs used different fine-tuning budgets. Their accuracy values therefore cannot establish that pruning itself caused an improvement.

Hardware-specific latency

Current latency observations were measured on the local Intel Mac environment and should not be generalized to GPUs, mobile accelerators or other CPUs.

Dense sparse-model storage

Unstructured pruning zeroes weights, but the current dense representation does not automatically reduce serialized model size.

Next research stage: run a converged baseline, matched compression training budgets, multiple random seeds and repeated hardware-controlled latency measurements before drawing publication-level conclusions.
