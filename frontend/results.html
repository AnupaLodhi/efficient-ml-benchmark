What are we learning?

Static INT8 strongly reduces storage.

The current model falls from approximately 42.70 MB to 10.78 MB, about a 74.8% reduction in file size.

Compression can hurt accuracy.

Static INT8 reaches 33.28% accuracy in the current local experiment, showing why model size cannot be evaluated alone.

FP16 is hardware dependent.

Although FP16 approximately halves storage, it was dramatically slower on this specific Intel Mac and PyTorch environment.

Sparsity does not guarantee a smaller file.

The current unstructured pruning implementation retains dense storage, so zero-valued weights still occupy serialized space.

Experimental caveat: these values are preliminary local pipeline-validation results. The shortened baseline used three training epochs. Each corrected pruning run then received three additional fine-tuning epochs after loading that baseline. Therefore higher post-pruning accuracy must not be interpreted as evidence that pruning itself improved accuracy. Final research evaluation requires matched budgets, multiple seeds, repeated latency measurements and controlled hardware.
